# Nimbus Core (product-a)

**Doc ID:** `product-a`
**Classification:** approved

Nimbus Core is a lightweight project-tracking tool aimed at small teams
(2-15 people). It ships with kanban boards, a single shared workspace, and
email notifications. There is no role-based access control; every team
member has full edit access to every board.

Nimbus Core is priced for simplicity, not depth: it intentionally omits
enterprise controls such as audit logging, SSO, or data residency options.
